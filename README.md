# Ridiculous at First Glance, Real by the Second

We train pigeons to deliver handwritten apology notes to blocked exes, because a sorry carried by a bird is the only apology they cannot swipe away unread.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
